环境 & 配置
🔄 首次使用 · 正在自动安装运行环境 · 装完自动打开 WebUI · 无需操作
Daemonkey 自动装环境 · 装坏了也能一键修。
首次使用 · 自动流程:
① 检测到环境未装会自动安装 (约 1-2 分钟 · 看底部终端)
② 装完自动启动 daemon 并打开 WebUI
③ 在 WebUI 里填 API key · 即可开聊。之后打开直接点『启动』。
① 安装 / 修复运行环境
建虚拟环境 (.venv) + 装依赖 · 第一次必跑 · 装坏了也点它修。 输出看底部终端。
② WebUI 访问口令 (本地鉴权 · 不是 LLM key)
给本机 WebUI 加一道口令防乱连 · 自动写入 .env · 用一次生成即可 · 与各家 API key 无关。
③ LLM API key —— 在 WebUI 里填
装好启动后 · 在网页右上『设置』里填各家 key 点保存即可 · 启动器不用配。 高级用户也可手动改 .env。
API · 官方主页 (拿 key / 充值)
Daemonkey 跑在你自己的 LLM key 上 (BYOK)。点开各家官网注册/充值拿 key · 推荐启动后在 WebUI 设置里填。

应急维修台 · 推荐先用
daemon 起不来 / 白屏先点这个。 直连 LLM 的终端 · 让 AI 像在 Cursor 里一样对话+用工具自己查自己修——精准修复、保留你的进展。 不需要 git · 独立窗口打开。
紧急回档 · 修不好再用
维修台也救不回来时才用。 一刀切回到 master 上次良好版本 (这段改动会回退 · 未提交改动 stash 收好不丢)。 需要 git。 输出看底部终端。
