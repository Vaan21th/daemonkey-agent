# Daemonkey mac-launcher

This branch is **launcher packaging only**.

It contains `mac_launcher.py`, `assets/` (HTML + skins + icons), and `tools/build_mac_app.sh`.
It does **not** contain the Daemonkey daemon source.

GitHub Actions on this branch builds `Daemonkey-<ver>-arm64.dmg` and `Daemonkey-<ver>-x86_64.dmg`.
