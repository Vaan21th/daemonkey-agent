# 发版实测 · 固定基线 + 本版重点

每发一版走两条轨，不要混：

1. **固定基线** —— 每版都要走完。不管这版改了什么。
2. **本版重点** —— 发这版之前现列清单。只测这版特意要看的。

改装、某个新页、某条升级补丁，都走第 2 条。不要塞进固定基线。

官方发版时，维护侧发布闸 [15] 认回执：机器半截 + 下面这条基线都齐、并且对上要寄出的那颗提交。回执不许带密钥。细则跟闸住在一起；本页是随仓带的同款清单。

## 固定基线（每版必测）

空依赖。从启动器开始。过了初见。名字出现在该出现的地方。陪伴能打开、能对话。工作台能打开、能对话。

到此为止。不必做到改装。

| 步 | 要看见什么 |
|---|---|
| 空盘子 | 新 clone，没有 `.venv`，没有 `.env`。桌上带着环境的旧目录不算 |
| 启动器 | 双击 `Daemonkey.exe`（或 `start.bat`）。看它装环境、拉起服务、打开页面。不要自己 `python tools/run_api_only.py` 当标准路径 |
| 端口 | 本机如果已经有一份在跑，空盘测试先设 `DK_PORT`（例如 `7869`），再开启动器。禁止空盘子连到别人的那一份上测 |
| 初见 | 相遇页填 key。DeepSeek 用官网那种**不带** `/v1` 的地址也要能过 |
| 名字 | 起的名字、怎么称呼你，工作台标题、陪伴房间、对话里对得上 |
| 工作台 | 页面能开，能发一句、有回。看板不要卡死 |
| 陪伴 | 房间能开（图在、不裂），能发一句、有回 |

`tools/empty_user_boot.ps1`（在维护用的发布闸一侧）只覆盖机器半截：空 clone、空盘装依赖、不带 `/v1` 的保存、相遇开口。**它代替不了启动器和两套界面。**
